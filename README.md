# WEB_DHV

Website portfolio cá nhân được thiết kế với giao diện hiện đại. Dự án dùng để giới thiệu thông tin cá nhân, kỹ năng và các sản phẩm nổi bật trong quá trình học tập và phát triển web.

## Chức năng nổi bật

* Giao diện hiện đại, tối giản
* Responsive trên nhiều thiết bị
* Hiệu ứng chuyển động mượt
* Hiển thị thông tin cá nhân và kỹ năng
* Showcase project cá nhân
