# 🌐 WEB DHV 
Một dự án web frontend tương tác cao được tối ưu hóa về mặt giao diện (UI/UX) và trải nghiệm người dùng, tích hợp các hiệu ứng chuyển động mượt mà bằng JavaScript.

🎯 **Demo trực tuyến:** [Xem trang web tại đây](https://trunghieuwdev.github.io/WEB_DHV/)

---

## 🚀 Tính Năng Nổi Bật

*   **Giao diện Responsive:** Hiển thị tối ưu và mượt mà trên mọi thiết bị (Desktop, Máy tính bảng, Điện thoại di động).
*   **Hiệu ứng Scroll Animation:** Các thành phần giao diện tự động xuất hiện sinh động khi người dùng cuộn trang.
*   **Tương tác mượt mà:** Xử lý các sự kiện click, hover và các hiệu ứng chuyển cảnh (transitions) bằng JavaScript thuần tối ưu.
*   **Cấu trúc chuẩn SEO:** Mã nguồn HTML5/CSS3 được tối ưu sạch sẽ, dễ dàng bảo trì và phát triển mở rộng.

---

## 🛠️ Công Nghệ Sử Dụng

Dự án được xây dựng hoàn toàn với các công nghệ Frontend cốt lõi nhằm đảm bảo tốc độ tải trang nhanh nhất:

| Công nghệ | Vai trò trong dự án |
| :--- | :--- |
| **HTML** | Xây dựng cấu trúc layout và nội dung ngữ nghĩa (Semantic Web). |
| **CSS** | Thiết kế giao diện, phối màu, hiệu ứng chuyển động và responsive flexbox/grid. |
| **JavaScript** | Xử lý logic tương tác, bắt sự kiện và điều khiển các hiệu ứng động trên trang. |
